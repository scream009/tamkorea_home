# 유튜브 첫 영상 — 롱폼/숏폼 판단 + 1화 대본

작성일: 2026-08-25
전제(확인 필요): 채널 목적은 **신뢰 구축 → 상담 유입(B2B)**, 주 시청자는 **중국인 손님을 받고 싶은 사장님**.
목적이 "인플루언서 모집"이나 "인지도 확보"라면 3번의 결론이 숏폼 쪽으로 바뀝니다.

---

## 1. 롱폼인가 숏폼인가 — 결론

**첫 영상은 롱폼(4~6분)으로 만들되, 같은 촬영분에서 숏폼 3편을 잘라 동시에 발행합니다.**

둘 중 하나를 고르는 문제가 아닙니다. 하나를 찍어서 둘로 내는 구조를 처음부터 잡는 게 맞습니다.

### 왜 롱폼이 본편인가

| 근거 | 설명 |
|---|---|
| 채널의 용도 | 사장님이 상담 전에 "이 회사 믿을 만한가" 확인하러 들어옵니다. 이때 필요한 건 도달이 아니라 **설명의 밀도**입니다. 30초로는 신뢰가 생기지 않습니다 |
| 소재의 성질 | 따종디엔핑·샤오홍슈는 **화면을 보여주며 설명해야** 이해됩니다. 검색 화면, 매장 페이지, 리뷰 구조 — 숏폼 길이에 안 들어갑니다 |
| 자산의 수명 | 롱폼은 채널 대문(고정 영상)으로 걸어두고 상담 메일·블로그·명함 QR에 계속 재사용합니다. 숏폼은 소비되고 사라집니다 |
| 전환 경로 | 숏폼 시청자는 스와이프로 넘어갑니다. 설명란 링크를 누르는 비율이 롱폼보다 현저히 낮습니다 |

### 그런데 왜 숏폼도 같이 내는가

구독자 0에서 롱폼만 올리면 **아무도 안 봅니다.** 이건 콘텐츠 품질과 무관한 구조 문제입니다.
숏폼은 채널 규모와 무관하게 노출이 돌기 때문에, 초기에는 **숏폼이 유일한 유입구**입니다.

정리하면 이 구조입니다.

```
숏폼 3편 (도달)  →  롱폼 1편 (신뢰)  →  블로그/상담 (전환)
```

숏폼은 "어? 저게 뭐지"까지만 하고, 판단은 롱폼에서 시키고, 행동은 설명란에서 받습니다.

### 하지 말아야 할 것

- **롱폼을 10분 이상으로 늘리는 것.** 광고 수익이 목적이 아니므로 길이를 채울 이유가 없습니다. 4~6분이 적정입니다
- **숏폼을 롱폼의 앞 30초로 자르는 것.** 도입부는 훅이 약합니다. 숏폼용 훅은 따로 씁니다(아래 5번)
- **첫 영상을 회사 소개로 만드는 것.** 아무도 모르는 회사의 소개 영상은 시청 지속시간이 바닥납니다. 정보를 먼저 주고 회사는 마지막 20초에 나옵니다

## 2. 1화 기획

- **제목:** 중국인 관광객은 네이버를 안 씁니다 | 사장님이 모르는 검색 앱 2개
- **길이:** 5분 내외
- **형식:** 화면 녹화(따종디엔핑·샤오홍슈 실제 화면) + 나레이션. **얼굴 출연 없이 제작 가능**합니다
- **오늘 저녁 블로그 글과 같은 주제** — 영상 설명란에 블로그 링크, 블로그 글에 영상 임베드. 서로 태웁니다
- **썸네일:** 왼쪽에 휴대폰 화면(따종디엔핑 검색 결과), 오른쪽에 큰 글씨 `네이버 아닙니다` / 하단 작게 `중국인 관광객 검색 앱`

## 3. 롱폼 대본 (5분)

> 표기: **[화면]** = 보여줄 것 / 나머지는 나레이션 그대로 읽으면 됩니다.

### 0:00 – 0:20 훅

**[화면]** 가게 앞에서 휴대폰을 보다가 그냥 지나가는 관광객 (스톡 영상 또는 직접 촬영)

가게 앞까지 온 중국인 손님이, 휴대폰을 한참 보다가 그냥 지나갑니다.
메뉴가 마음에 안 들어서가 아닙니다.
그 손님 휴대폰 화면에, 사장님 가게가 아예 없었기 때문입니다.

**[화면]** 검색 결과 목록에서 특정 가게만 빠져 있는 그래픽

오늘은 그 이유를 5분 안에 정리해드리겠습니다.

### 0:20 – 1:10 문제 정의

**[화면]** 네이버 지도 화면 → X 표시

한국 손님은 네이버로 가게를 찾습니다. 이건 다들 아십니다.
그래서 네이버 플레이스를 관리하고, 블로그 체험단도 하십니다. 맞는 방향입니다.

문제는 중국인 관광객에게는 이게 **하나도 작동하지 않는다**는 겁니다.
중국에서는 네이버도, 구글도, 인스타그램도 안 됩니다.
카카오맵도 안 씁니다.

**[화면]** 앱 아이콘들이 하나씩 회색으로 꺼지는 그래픽

그럼 이 사람들은 뭘 보고 가게를 찾을까요.
딱 두 개입니다.

### 1:10 – 2:30 앱 1 — 샤오홍슈

**[화면]** 샤오홍슈 앱 실행 → "제주 맛집" 중국어 검색 → 결과 스크롤

첫 번째는 샤오홍슈입니다. 중국어로 小红书, 작은 빨간 책이라는 뜻입니다.

우리로 치면 **인스타그램과 네이버 블로그를 합쳐놓은 앱**입니다.
사진 위주인데, 그 아래 후기가 길게 붙습니다.

중국인 관광객은 한국 오기 전에, 혹은 숙소에서 여기부터 켭니다.
"제주 맛집", "제주 카페" 이렇게 검색하고, 다른 중국인이 올린 사진을 보고 가고 싶은 곳을 저장합니다.

**[화면]** 저장(收藏) 버튼 누르는 장면 클로즈업

중요한 건 여기서 **검색되는 건 가게가 아니라 콘텐츠**라는 점입니다.
누군가 우리 가게 사진을 올려놨어야 검색에 걸립니다.
아무도 안 올렸으면, 그 손님 여행 계획에 우리 가게는 처음부터 없습니다.

### 2:30 – 3:40 앱 2 — 따종디엔핑

**[화면]** 따종디엔핑 앱 → 지역 제주 설정 → 매장 페이지 열기 (평점·리뷰·영업시간 순서로 짚기)

두 번째는 따종디엔핑입니다. 大众点评, 대중점평이라고도 부릅니다.

이건 **중국판 네이버 스마트플레이스**라고 보시면 정확합니다.
위치, 영업시간, 메뉴, 가격, 평점, 리뷰가 전부 여기 모입니다.

샤오홍슈에서 마음에 든 가게를 저장했으면, 실제로 갈지 말지는 여기서 정합니다.
평점 몇 점인지, 지금 여는지, 리뷰가 몇 개인지 확인하고 나서 출발합니다.

**[화면]** 두 앱을 화살표로 잇는 도식: 샤오홍슈(발견) → 따종디엔핑(확인) → 방문

그러니까 순서가 이렇습니다.
샤오홍슈에서 **발견**되고, 따종디엔핑에서 **확인**돼야, 방문이 일어납니다.
둘 중 하나만 비어 있어도 그 손님한테 우리 가게는 없는 가게입니다.

### 3:40 – 4:30 미등록이면 벌어지는 일

**[화면]** 검색 결과 목록 — 옆 가게는 있고 우리 가게는 없는 화면

미등록 상태를 그냥 두면 세 가지가 일어납니다.

하나. 검색 목록에 **아예 없습니다.** 순위가 낮은 게 아니라 없습니다.
바로 옆 가게가 등록돼 있으면, 그 손님은 옆 가게로 갑니다.

**[화면]** 정보가 틀린 매장 페이지 예시 (영업시간 회색 처리)

둘. 사장님도 모르는 사이에 **손님이 대신 등록해놨을 수 있습니다.**
따종디엔핑은 이용자가 가게를 등록할 수 있습니다.
없어진 메뉴, 옛날 영업시간, 흐릿한 사진으로 페이지가 만들어져 있는 경우, 생각보다 많습니다.

셋. 만족한 손님이 후기를 남기려 해도 **남길 자리가 없습니다.**
좋은 경험이 다음 손님을 못 부르고 그냥 사라집니다.

### 4:30 – 5:00 정리 + CTA

**[화면]** 3줄 요약 자막

정리하겠습니다.

중국인 관광객은 샤오홍슈에서 발견하고, 따종디엔핑에서 확인하고, 방문합니다.
우리 가게가 지금 그 두 곳에 어떤 상태로 있는지, 이것부터 확인하셔야 합니다.

확인 방법은 설명란 링크에 글로 정리해뒀습니다. 3분이면 직접 해보실 수 있습니다.

**[화면]** 탐코리아 로고 + 연락처 (여기서 처음이자 마지막으로 회사 노출)

직접 확인이 어려우시면 상호만 알려주세요. 조회해서 알려드리겠습니다.
매장 등록은 무료로 도와드리고 있습니다.

다음 영상에서는 등록한 다음에 뭘 해야 하는지, 리뷰를 어떻게 쌓는지 다루겠습니다.

## 5. 숏폼 3편 (같은 소재에서 파생, 각 30~45초)

숏폼은 **롱폼 도입부를 자르지 않고 훅을 새로 씁니다.** 첫 1초가 전부입니다.

### 숏폼 1 — "네이버가 아닙니다" (가장 먼저 발행)
- **0:00** (훅) "중국인 손님이 가게 앞까지 왔다가 그냥 갑니다. 이유 아세요?"
- **0:05** "휴대폰에 사장님 가게가 없어서입니다."
- **0:10** "중국에서는 네이버도 구글도 인스타도 안 됩니다." **[화면]** 아이콘 꺼지는 그래픽
- **0:20** "샤오홍슈에서 찾고, 따종디엔핑에서 확인합니다." **[화면]** 실제 앱 화면
- **0:30** "우리 가게가 거기 있는지, 확인해보셨어요?" → 롱폼 유도

### 숏폼 2 — "사장님 모르게 등록돼 있습니다"
- **0:00** (훅) "따종디엔핑에 우리 가게, 이미 등록돼 있을 수 있습니다. 사장님 모르게요."
- **0:08** "이용자가 직접 가게를 등록할 수 있거든요." **[화면]** 정보 틀린 페이지 예시
- **0:20** "없어진 메뉴, 옛날 영업시간, 흐릿한 사진. 그대로 손님이 봅니다."
- **0:30** "리뷰까지 쌓이면 고치기 더 번거로워집니다. 오늘 검색해보세요."

### 숏폼 3 — "3분 자가진단"
- **0:00** (훅) "3분이면 확인됩니다. 우리 가게가 중국인한테 보이는지."
- **0:06** "따종디엔핑 앱 열고, 지역을 제주로 바꾸고" **[화면]** 실제 조작
- **0:15** "**중국어 상호**로 검색하세요. 한글로는 안 나옵니다."
- **0:25** "결과 없으면 미등록, 정보 틀리면 남이 등록한 겁니다."
- **0:35** "중국어 상호가 없으면? 그것부터 정해야 합니다." → 롱폼 유도

| 순서 | 내용 | 시점 |

숏폼 3편의 반응(조회수·시청 완료율)을 보고 2화 주제를 정하면 됩니다.
반응이 좋은 훅이 곧 사장님들이 실제로 걸려드는 문장입니다.

## 7. 제작 부담을 줄이는 방법

- 얼굴 출연 불필요 — **화면 녹화 + 나레이션**으로 충분합니다. 오히려 화면을 보여주는 쪽이 신뢰가 높습니다
- 나레이션이 부담되면 자막 + 배경음악만으로도 성립합니다. 다만 목소리가 있는 쪽이 체류시간이 깁니다
- 화면 녹화는 실제 따종디엔핑에서 **경쟁 매장이 잘 등록된 사례**를 하나 골라 보여주면 설득력이 올라갑니다
  (특정 매장을 부정적으로 지칭하지 않도록 주의 — 잘 된 사례만 노출)
- 5분 대본 = 나레이션 기준 약 900~1,000자. 위 대본이 그 분량입니다
